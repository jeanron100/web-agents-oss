# v0.1.0-rc.5 发布验证与后续计划

[公开仓库](https://github.com/jeanron100/web-agents-oss) · [候选版与交付附件](https://github.com/jeanron100/web-agents-oss/releases/tag/v0.1.0-rc.5) · [发布工作流](https://github.com/jeanron100/web-agents-oss/actions/runs/38834999760)

定位为单管理员或可信小团队的 Linux 管控台，当前验收平台为 Linux amd64。现有原生部署可以独立升级控制台，不需要迁入容器。

## 实际验证

- GitHub 全新环境：后端 935 项通过、11 项可选集成跳过；前端 234 项通过，TypeScript/构建通过；Compose 首次安装通过。
- 应用 npm 依赖扫描无已知漏洞；最终镜像通过可修复 HIGH/CRITICAL 门槛。扫描使用 `ignore-unfixed=true`，不表示不存在其他等级或未修复漏洞。
- 原生隔离工作区和发布前候选容器中的真实 Codex/Kimi：命令、文件修改、图片、中断与恢复；Codex 即时补充与后续任务排队。
- 最终镜像替换 runner 后，管理员配置与账号/工作区卷保留；既有 Codex、Kimi 会话可重新加载并完成新任务。最后的镜像修复为执行 Claude 官方安装脚本，业务代码及 Codex/Kimi 版本未改变。
- 真浏览器：首次登录、服务器增删改/禁用及令牌不回显；1440/390/320 宽度无横向溢出和脚本错误。
- 匿名终端拒绝；登录后经 Hub/节点鉴权执行终端命令，读取真实任务文件；stdio MCP 列出 8 个工具并查询实际节点。
- MySQL 标记记录备份、删除、恢复后读回；恢复后管理员仍能登录，runner 容器未因控制台备份而重建。
- 干净导出清单逐文件 SHA-256 验证；非测试凭据匹配为 0。原私人 Git 历史没有公开。

固定 CLI 为 Codex 0.159.2、Kimi Code 2.2.0、Claude Code 2.1.301。构建会以非 root 用户实际运行三个版本命令。Claude 仅验证可执行文件和版本，未登录厂商账号进行推理验收；用户仍需使用自己的合法账号。许可来源与交付条件见 [第三方说明](third-party-notices.md)。

## 使用边界

控制台重启不终止远程原生 CLI；runner 替换会停止其内部进程，需保留卷并恢复会话。控制台备份不包含 runner 账号与工作区卷。尚未验证 arm64、Windows 原生节点或不可信用户之间的隔离，不能据此宣称多租户安全。

## 后续优先级

P1：节点向导内的厂商登录状态实测、CLI 兼容矩阵、可视化升级/回滚与备份状态、持续故障提示，以及更轻的按引擎选择的 runner。

P2：多用户/RBAC、项目级隔离、配额与成本策略、通知渠道扩展，以及更轻的单节点存储方案。优先保持从空环境安装到首个真实任务的完整体验。
